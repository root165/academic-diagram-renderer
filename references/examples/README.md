# Example evidence images

These images are kept for visual comparison with the definitions in the parent `references/` folder.

- `P1`–`P7` are user-supplied examples from the project discussion. They demonstrate the expected visual grammar, but they are not normative sources. Some carry third-party watermarks; verify permission before redistributing them outside this project.
- `A1` is Figure 4.1-6 from NASA Contractor Report 177625, *Software Engineering Guidebook* (1993), a U.S. government publication; it is a transaction-type SC example.
`P7` is a user-supplied teaching example of a transform-type SC (input branch → central transform → output branch).
- `A2` is Figure 14.36 from the OMG UML 2.5.1 specification (2017), an OMG standard document.

The source links and evidence levels are recorded in `../authority-map.md`. When a user-supplied example conflicts with a formal standard, the standard wins; when the example is merely a layout convention, label it as such.
